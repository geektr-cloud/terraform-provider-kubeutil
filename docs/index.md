# kubeutil Provider

The kubeutil provider opens process-scoped Kubernetes port-forward tunnels and
returns a `127.0.0.1` endpoint that Terraform or OpenTofu can consume during the
current command. It manages no Kubernetes objects: it reads target metadata,
lists pods for selector targets, and forwards a port to a `Running` pod.

-> The provider requires Terraform 1.10 or later, or OpenTofu 1.12 or later,
because it defines an ephemeral resource.

!> A tunnel is valid only for the command and provider process that opened it.
Prefer `ephemeral.kubeutil_tunnel`. `data.kubeutil_tunnel` persists an endpoint
that is dead in any later command, and applying a saved plan in a new process
cannot revive it.

## Example Usage

```hcl
terraform {
  required_providers {
    kubeutil = {
      source = "geektr-cloud/kubeutil"
    }
  }
}

provider "kubeutil" {
  config_path       = "~/.kube/config"
  config_context    = "staging"
  default_namespace = "app"
}

ephemeral "kubeutil_tunnel" "api" {
  target = "service/api"
  port   = "http"
}

# A provisioner is a legal consumer of an ephemeral value. Root-module outputs
# are not, even with ephemeral = true.
resource "terraform_data" "api_smoke_test" {
  provisioner "local-exec" {
    environment = {
      KUBEUTIL_ENDPOINT = ephemeral.kubeutil_tunnel.api.hostport
    }
    command = "curl -fsS \"http://$KUBEUTIL_ENDPOINT/\" > /dev/null"
  }
}
```

## Authentication

Configuration mirrors the Kubernetes provider and is merged in memory through
client-go. Explicit attributes win over `KUBE_*` environment variables, which win
over kubeconfig files, which win over in-cluster service account credentials. No
temporary kubeconfig is written.

Notable environment variables: `KUBE_HOST`, `KUBE_USER` (not `KUBE_USERNAME`),
`KUBE_PASSWORD`, `KUBE_TOKEN`, `KUBE_CONFIG_PATH`, `KUBE_CONFIG_PATHS`,
`KUBE_CTX`, `KUBE_CTX_AUTH_INFO`, `KUBE_CTX_CLUSTER`, `KUBE_PROXY_URL`, and
`KUBE_NAMESPACE` for `default_namespace`.

`password`, `token`, `client_key`, and `exec.env` are Sensitive, which redacts
CLI output only. It is not encryption. When an `exec` block is present,
`api_version` and `command` must be set, even though framework schema rendering
marks those nested attributes optional.

### Optional

- `client_certificate` (String) PEM-encoded client certificate for TLS authentication. Can also be set with KUBE_CLIENT_CERT_DATA.
- `client_key` (String, Sensitive) PEM-encoded client certificate key for TLS authentication. Can also be set with KUBE_CLIENT_KEY_DATA.
- `cluster_ca_certificate` (String) PEM-encoded root certificate bundle for TLS authentication. Can also be set with KUBE_CLUSTER_CA_CERT_DATA.
- `config_context` (String) Name of the kubeconfig context to use. Can also be set with KUBE_CTX.
- `config_context_auth_info` (String) Name of the kubeconfig authentication information to use. Can also be set with KUBE_CTX_AUTH_INFO.
- `config_context_cluster` (String) Name of the kubeconfig cluster to use. Can also be set with KUBE_CTX_CLUSTER.
- `config_path` (String) Path to a kubeconfig file. Conflicts with config_paths. Can also be set with KUBE_CONFIG_PATH.
- `config_paths` (List of String) List of kubeconfig files used in order of precedence. Conflicts with config_path. Can also be set with KUBE_CONFIG_PATHS, split with the OS path list separator.
- `default_namespace` (String) Namespace used by tunnel instances that do not set their own namespace. Defaults to the credential context namespace, then to the literal namespace "default". Can also be set with KUBE_NAMESPACE.
- `exec` (Block, Optional) Configure an exec credential plugin. At most one block is allowed. (see [below for nested schema](#nestedblock--exec))
- `host` (String) The hostname (in the form of a URI) of the Kubernetes API server. Can also be set with KUBE_HOST.
- `insecure` (Boolean) Whether the server should be accessed without verifying the TLS certificate. Can also be set with KUBE_INSECURE.
- `password` (String, Sensitive) Password for HTTP basic authentication against the Kubernetes API server. Can also be set with KUBE_PASSWORD.
- `proxy_url` (String) URL of a proxy used for all API requests. Can also be set with KUBE_PROXY_URL.
- `tls_server_name` (String) Server name passed to the server for SNI and used to check the server certificate. Can also be set with KUBE_TLS_SERVER_NAME.
- `token` (String, Sensitive) Bearer token used to authenticate. Can also be set with KUBE_TOKEN.
- `username` (String) Username for HTTP basic authentication against the Kubernetes API server. Can also be set with KUBE_USER.
