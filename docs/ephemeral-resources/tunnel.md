# kubeutil_tunnel (Ephemeral Resource)

Opens a Kubernetes port-forward tunnel to an abstract target port and returns a
loopback endpoint that is not persisted in plan or state. This is the recommended
surface: the ephemeral lifecycle matches a tunnel that only exists while the
provider process runs.

~> An ephemeral value cannot be used in an ordinary resource argument, and a
root-module output cannot consume it even with `ephemeral = true`. Legal
consumers include provisioner and provider configuration blocks, write-only
arguments where the CLI supports them, and other ephemeral resources.

## Example Usage

```hcl
ephemeral "kubeutil_tunnel" "api" {
  target    = "service/api"
  port      = "http"
  namespace = "app"

  healthcheck {
    type = "telnet"
  }
}

resource "terraform_data" "api_smoke_test" {
  provisioner "local-exec" {
    environment = {
      KUBEUTIL_ENDPOINT = ephemeral.kubeutil_tunnel.api.hostport
    }
    command = "curl -fsS \"http://$KUBEUTIL_ENDPOINT/\" > /dev/null"
  }
}
```

Outputs:

- `host`: always `127.0.0.1`
- `local_port`: the OS-assigned port
- `hostport`: `127.0.0.1:<local_port>`
- `namespace`: the effective namespace

The endpoint stays valid for as long as the provider process keeps the tunnel. It
does not survive the command, and it is never restored from state.

`Close` releases this instance's reference to the shared tunnel. Other ephemeral
instances with the same identity keep it alive until they close too. The last
release stops the keeper and closes the listener.

If the forwarding stream fails, the tunnel reconnects with backoff from `1s` to
`30s` and re-resolves the target, which may move it to a different pod. The local
port stays the same, but the listener is down while reconnecting and existing
connections are cut.

`healthcheck { type = "telnet" }` is a negative rejection check only, bounded by
the remaining `timeout`. A successful local handshake does not prove the remote
port is open or the application is healthy. `type` must be set whenever the block
is present, even though framework schema rendering marks the nested attribute
optional.

## RBAC

Requires `get` on the target, `get`/`list`/`watch` on pods for selector targets,
and `create` on `pods/portforward`.

## Schema

### Required

- `port` (String) Remote port of the target: a number (5432), a port name (postgres), or a number with an empty local component (:5432). A non-empty local port is rejected; the provider always allocates a random local port on 127.0.0.1.
- `target` (String) Target of the tunnel: a bare pod name or TYPE/NAME. TYPE accepts pod, service, deployment, replicaset, statefulset, daemonset, job, and replicationcontroller, plus common kubectl aliases such as po, svc, deploy, rs, sts, ds, and rc. Custom resources and group/version-qualified names are not supported.

### Optional

- `healthcheck` (Block, Optional) Optional healthcheck run on every acquisition, including a shared tunnel. telnet opens the local listener without sending application data and observes the forwarding path briefly; it is negative rejection detection, not proof of remote application health. (see [below for nested schema](#nestedblock--healthcheck))
- `namespace` (String) Namespace of the target. Defaults to the provider's default_namespace, which in turn defaults to the credential context namespace and then to the literal namespace "default".
- `timeout` (String) Maximum time for the whole acquisition (target read, pod selection, port resolution, initial upgrade and listener, and the optional healthcheck), as a Go duration such as 60s. Defaults to 60s. This is not a request timeout and does not limit the lifetime of the tunnel.

### Read-Only

- `host` (String) Loopback address the tunnel listens on. Always 127.0.0.1.
- `hostport` (String) Consumer-facing endpoint of the tunnel, 127.0.0.1:<local_port>.
- `local_port` (Number) OS-assigned local port of the tunnel listener.
